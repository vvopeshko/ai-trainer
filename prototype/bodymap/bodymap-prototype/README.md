# Body Map Prototype

Сравнение двух подходов к визуализации мышечной нагрузки на тренировке:
- **Самописный SVG** (стилизованный, легковесный, гибкий)
- **react-body-highlighter** (готовая npm-библиотека, анатомически точная)

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`.

## Структура

```
bodymap-prototype/
├── package.json
├── vite.config.js
├── index.html
└── src/
    ├── main.jsx                  # точка входа React
    └── BodyMapComparison.jsx     # основной компонент со всем кодом
```

В одном файле `BodyMapComparison.jsx` лежит всё:
- база упражнений `exerciseDatabase` (упражнение → primary/secondary мышцы)
- 4 тренировочных дня программы
- маппинг наших идентификаторов мышц на формат библиотеки
- компонент `CustomBodyMap` — самописный SVG
- компонент `LibBodyMap` — обёртка над `react-body-highlighter`
- сравнительная таблица

## Что посмотреть

1. Переключай дни кнопками сверху — увидишь, как обе схемы реагируют на разные мышцы.
2. Слева — мой самописный SVG (упрощённый силуэт + цветные регионы).
3. Справа — реальная библиотека с анатомически точными полигонами.

## Главные различия по архитектуре

**Самописный SVG:**
- Каждая мышца — отдельный `<path>` или `<ellipse>` с уникальным `id`.
- Интенсивность подсветки — 4 уровня (0 / лёгкая / средняя / приоритет), вычисляется через `calculateMuscleVolume` исходя из количества подходов и роли (primary × 1.0 + secondary × 0.4).
- Есть **разделение** на `upper-chest` / `mid-chest`, три пучка дельт (front/side/rear), `lats` отдельно от `mid-back`.

**react-body-highlighter:**
- Принимает массив `[{ name, muscles: [...] }, ...]` — список упражнений с мышцами.
- Подсветка идёт **по частоте** упоминания мышцы. Чтобы получить градиент интенсивности, дублирую упражнение в массиве по количеству подходов (см. `getLibData`).
- Не различает верх/середину груди (только `chest`), нет средней дельты (только `front-deltoids` / `back-deltoids`), широчайшие и середина спины объединены в `upper-back`.
- Маппинг наших идентификаторов на её формат лежит в константе `mapToLib`.

## Что менять при интеграции в свой проект

1. **`exerciseDatabase`** — заменить на свою базу (или вынести в БД).
2. **`workouts`** — приходит с бэкенда / из локального стейта.
3. **Выбор компонента** — оставить тот, что подходит, удалить другой.
4. **Цвета и стили** — сейчас захардкожены inline, в проде логичнее вынести в Tailwind / CSS-переменные.

## Альтернативы для рассмотрения

- **react-muscle-highlighter** (форк) — поддерживает `intensity` из коробки (1-5), `slug`-based API, чище в использовании. См. https://github.com/soroojshehryar/react-muscle-highlighter
- **body-highlighter** (lahaxearnaud) — framework-agnostic, активно поддерживается. См. https://github.com/lahaxearnaud/body-highlighter
- **react-native-body-highlighter** — если когда-нибудь будет нативное приложение, основная библиотека для React Native. См. https://github.com/HichamELBSI/react-native-body-highlighter

## Возможные доработки

- **Кликабельные регионы** в самописном SVG: добавить `onClick` на каждый `<path>`, открывать модалку со списком упражнений для этой мышцы.
- **Тепловая карта за неделю**: агрегировать `volumes` по всем тренировкам недели, подсвечивать недогруженные группы относительно целевых значений.
- **План vs факт**: рендерить два слоя — план серым, фактически выполненные подходы цветом.
- **Анимация наведения**: при ховере на мышцу — тултип с количеством подходов.
